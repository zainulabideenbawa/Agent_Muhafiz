# Frequently Asked Questions (FAQs)

## Q1. Can team leads apply or pitch solo without a team?
**A:** No. A minimum team of 2 members is mandatory for pitching rounds. Maximum is 5 members.

## Q2. Are tech enthusiasts under 18 eligible for the hackathon?
**A:** The age limit for participants **must be** 18 – 45 years.

## Q3. What is the submission process and timeline?
**A:** Selected participants receive the Challenges Document and a Google Form for Challenge Selection. Read both thoroughly.

**Important Dates:**
- **May 15, 2026** – Deadline to select and submit your challenge/idea (choose only 1 challenge and deploy your solution).
- **May 20, 2026** – Final project submission deadline (instructions will be shared separately).
- **May 25–26, 2026** – Virtual Regional Pitching Rounds.
- **June 07, 2026** – National Finale in Islamabad (logistic support provided ONLY from Lahore/Karachi to Islamabad).

From all submissions, 10–15 teams will be shortlisted from each region for virtual pitching. Regional winners/runners‑up will qualify for the National Finale.

## Q4. Can we use tools like n8n, Google AI Studio, Vertex AI, LangGraph, CrewAI, or external services with Antigravity?
**A:** Yes, as long as Antigravity remains the main orchestrator and development logs/reasoning traces can be submitted. You are free to build agents in any framework (Vertex AI, LangGraph, etc.) and connect them via Antigravity.

## Q5. Are the provided $5 credits enough for the hackathon?
**A:** Each team member receives $5 credit. Additional GCP credits can be facilitated if required. Credits are intended for solution development on Google Cloud Platform services.

## Q7. Can we use other LLMs inside Antigravity?
**A:** Yes, provided your solution operates within the Antigravity environment and Antigravity is the primary orchestrator.

## Q8. Is Mobile app mandatory?
**A:** Yes. A mobile app is mandatory for all challenges. Web app is optional.

## Q9. Do we have to submit the final solution on May 15?
**A:** No. May 15 is only for challenge/idea selection. The final project submission is due **May 20, 2026**.

## Q10. Can we use our previous Phase #1 project in the Hackathon?
**A:** No. You must build your solution based on the explicit requirements of the selected challenge.

## Q11. Can we make changes in the team composition?
**A:** Yes. You may modify team composition during development, but must submit finalized team details with the final project.

## Q12. Is a full mobile app required, or can teams build a web app/dashboard and keep the mobile app minimal (e.g., just for alerts)?
**A:** A working prototype with a mobile app is mandatory across all challenges; a web app/dashboard is optional.

## Q13. Are Progressive Web Apps (PWAs) allowed (converting a web app to an APK), or does the app need to be built and compiled natively (e.g., using Kotlin)?
**A:** Only APKs are acceptable.

## Q14. Can teams use a pre‑existing MVP and simply integrate Antigravity features into it, or must the project be built entirely from scratch?
**A:** The project must be built in Antigravity and from scratch.

## Q15. Are participants allowed to build an app that falls outside of the 4 official challenges?
**A:** **NO**.

## Antigravity & AI Tools
- **Q16:** Must we use Antigravity exclusively?
  - **A:** You must use Google Antigravity as the core platform/orchestrator, but external LLMs, APIs, databases, and visualization tools are permitted.
- **Q17:** Minimum required use of Antigravity?
  - **A:** Antigravity must orchestrate complex workflows: intent understanding, reasoning, planning, tool/API integration, and action execution.
- **Q18:** Can teams use extensions within Antigravity?
  - **A:** Yes.
- **Q19:** Antigravity credits and $5 credit limit?
  - **A:** Only Google Cloud credits are provided. Initially $5 each and can be requested multiple times if exhausted.

## APIs & Technical Implementation
- **Q20:** How to provide/log prompts and transactions?
  - **A:** Submit Antigravity agent traces/logs showing IDE reasoning steps, task plans, tool calls, decision rationale, action execution, and fallback behavior.
- **Q21:** Where to get API keys for Google Maps, weather, emergency alerts?
  - **A:** Use Google Cloud APIs (covered by credits). For other services, free versions may be used.

## Submissions & Demos
- **Q22:** Demo video language and voiceover?
  - **A:** No compulsion on language or voice method. Presentations should clearly showcase the product.
- **Q23:** If Antigravity setup lacks native simulation, how to demonstrate workflow?
  - **A:** Simulate the use case through the built app.
- **Q24:** Grand finale expectations?
  - **A:** Details will be shared after Regional Rounds.

**Note:** All questions must be asked in official community channels or Discord; direct messages will not be addressed.
